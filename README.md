# 🌾 Portfólio Pessoal - Inspiração Stardew Valley

Um portfólio interativo e temático inspirado na estética **pixel art**, paleta de cores e elementos de interface do jogo **Stardew Valley**. O projeto une nostalgia e criatividade com desenvolvimento Front-end moderno, transformando a navegação por projetos, habilidades e trajetória profissional em uma experiência lúdica.

---

## 🚀 Destaques e Recursos

- 🎨 **Identidade Visual Pixel Art:** Interface fiel aos elementos clássicos do universo do jogo, incluindo caixas de diálogo, molduras estilizadas, ícones temáticos e tipografia retrô.
- 🌗 **Alternância de Tema (Dia / Noite):** Troca dinâmica entre os modos claro e escuro via JavaScript, simulando o ciclo de dia e noite característico do jogo.
- 📊 **Barras de Habilidades (Skills):** Apresentação interativa das tecnologias dominadas no formato de níveis de experiência.
- 📁 **Vitrine de Projetos & Contato:** Exibição organizada dos principais trabalhos desenvolvidos e canais diretos para contato profissional.
- 📐 **Layout Responsivo:** Construído com **Tailwind CSS** para garantir adaptação fluida em smartphones, tablets e desktops sem perder a fidelidade estética.

---

## 🛠️ Tecnologias Utilizadas

- **[HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML):** Estruturação semântica das seções da página.
- **[Tailwind CSS](https://tailwindcss.com/):** Estilização utilitária, customização de cores, bordas temáticas, responsividade e controle de tema dark/light.
- **[JavaScript (ES6+)](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript):** Interatividade dos componentes, manipulação do DOM, alternância de temas e controle de navegação.
- **[Git & GitHub](https://github.com/):** Versionamento de código e hospedagem.

## 🔧 Como Executar o Projeto Localmente

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/NatiPeralta/stardew-valley-portfolio](https://github.com/NatiPeralta/stardew-valley-portfolio.git)

2. **Acesse a pasta do projeto:**
   ```bash
   cd portfolio-stardew-valley

3. **Instale as dependências (caso utilize Tailwind via CLT/PostCSS):**
  ```bash
  npm install
  ```

4. Abra o projeto no navegador:
  Abra o index.html diretamente no navegador (ou utilize a extensão Live Server no VS Code).
